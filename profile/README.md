# Algorithms

## Overview

This organization contains focused implementations of fundamental computer science algorithms and data structures in Java.

The goal is to build a deep understanding of how these concepts work internally by implementing them from first principles and exploring their performance characteristics, tradeoffs, and real-world applications.

---

## Purpose

This organization exists to:

- Strengthen core computer science fundamentals
- Build intuition for algorithmic problem solving
- Explore the implementation details of common data structures and algorithms
- Connect theoretical concepts to practical software engineering

---

## Repositories

### Data Structures

Implementations of fundamental data structures, including their operations, complexity analysis, and design tradeoffs.

Examples include:
- Arrays
- Linked Lists
- Stacks
- Queues
- Hash Maps
- Trees
- Heaps
- Tries

---

### Sorting

Implementations and comparisons of common sorting algorithms, focusing on performance, stability, memory usage, and appropriate use cases.

Examples include:
- Merge Sort
- Quick Sort
- Heap Sort
- Insertion Sort
- Selection Sort
- Bubble Sort

---

### Graphs

Graph representations and traversal algorithms, along with common graph problems and optimization techniques.

Examples include:
- Breadth-First Search (BFS)
- Depth-First Search (DFS)
- Topological Sort
- Shortest Path Algorithms
- Minimum Spanning Trees
- Union-Find

---

### Dynamic Programming

A collection of classic dynamic programming problems and patterns designed to build intuition for recognizing and solving optimization problems.

Topics include:
- Memoization
- Tabulation
- Knapsack
- Longest Common Subsequence
- Grid Problems
- State Transition Design

---

## Philosophy

Each repository is intentionally focused on a single area of computer science rather than a collection of unrelated exercises.

Implementations prioritize:
- Readability
- Correctness
- Performance analysis
- Clear documentation
- Incremental improvement over time

---

## Status

This organization is an active learning and engineering portfolio. Repositories will continue to evolve with additional implementations, documentation, benchmarks, and design notes.
